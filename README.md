MVideo v2 - 轻量现代化影视搜索播放平台

MVideo v2 是一款基于 PHP 开发的轻量级影视资源搜索与在线播放系统，以「多源聚合、安全可控、跨端适配」为核心优势，无需复杂部署，开箱即可使用，为用户提供流畅便捷的影视观看体验，同时支持高度个性化配置，满足不同场景的使用需求。

✨ 核心亮点

🎬 影视体验 · 流畅高效

- 多源聚合搜索：整合多个优质影视源站，资源覆盖电影、电视剧、动漫、综艺等全品类，搜索结果精准丰富，告别单一源站资源匮乏问题。

- 高清在线播放：内置 ArtPlayer 专业播放器，支持 m3u8/mp4 等主流格式，搭配 HLS.js 流媒体解析，播放流畅不卡顿，支持倍速、全屏等自定义控制。

- 智能断点续看：自动记录观看历史与播放进度，再次打开影片可直接续播，无需手动定位，观影体验更连贯。

- 直观选集交互：优化剧集选集界面，分类清晰、切换便捷，支持快速跳转至目标集数，避免繁琐操作。

🔒 安全防护 · 可控可靠

- 分层密码保护：支持全局密码验证与关键词分类保护，可针对性限制敏感内容访问，有效规避风险。

- 灵活会话管理：可配置验证超时时间，超时后自动失效，兼顾便捷性与安全性，支持手动退出验证状态。

- 本地数据隔离：观看记录等数据存储于用户本地（LocalStorage/Cookie），无服务器存储，保护用户隐私安全。

- 基础安全防护：支持 XSS 防护机制，输出内容自动过滤，降低恶意攻击风险，保障平台稳定运行。

🎨 交互设计 · 适配全场景

- 明暗主题切换：支持手动切换浅色/深色主题，同时兼容系统主题跟随，偏好设置自动保存，适配不同使用环境。

- 全端响应式布局：完美适配桌面端、平板、移动端，界面元素自适应调整，触控操作友好，随时随地轻松观影。

- 轻量化无依赖：前端基于原生 JS 开发，无需引入冗余框架，加载速度更快，降低浏览器性能占用。

- 个性化定制：支持自定义站点标题、描述、主题颜色等，可根据需求调整外观与功能参数，打造专属平台。

🚀 部署使用 · 简单易用

- 低环境要求：仅需 PHP 7.4+ 环境与 cURL 扩展，支持 Nginx/Apache 等主流服务器，无需数据库，部署门槛极低。

- 一键快速配置：复制配置模板即可修改核心参数，支持片源数量调整、密码设置、关键词保护等，新手也能快速上手。

- 灵活 API 扩展：支持自定义更换影视 API 源，适配不同接口格式，轻松扩展资源渠道，避免源站失效问题。

git clone https://github.com/your-username/mvideo.git

2. 配置核心参数：复制配置模板并修改，无需复杂配置
        # 复制配置模板
cp config/config.example.php config/config.php

# 编辑配置（核心参数示例）
return [
  'site_title' => 'MVideo - 影视搜索平台', // 站点标题
  'video_password' => 'your-secure-pwd',    // 保护内容访问密码

  'verification_timeout' => 2,              // 验证有效期（小时）
  'm_accent_color' => '#3b82f6',            // 浅色主题主色
  'a_accent_color' => '#60a5fa'             // 深色主题主色
];

       chmod -R 755 config/

        访问地址：http://你的域名/ 或 http://服务器IP/mvideo

🛠 技术架构

前端技术栈

HTML5（语义化结构）+ CSS3（响应式布局/CSS变量主题）+ 原生 JavaScript（交互逻辑），搭配 ArtPlayer 播放器、HLS.js 流媒体解析、Font Awesome 图标库，实现轻量化与高性能兼顾。

后端技术栈

基于 PHP 实现服务端逻辑，通过 cURL 处理第三方 API 请求，利用 Session 管理用户验证状态，结合文件缓存优化数据处理，无需数据库依赖，降低部署与维护成本。

📖 核心使用指南

1. 影视搜索与播放

在首页搜索框输入影片名称（支持模糊搜索），选择片源后点击搜索，从结果列表中选择影片即可进入播放页；播放页支持选集、倍速、全屏等操作，自动记录播放进度。

2. 密码验证与权限控制

访问含保护关键词的内容时，会自动弹出密码验证界面，输入正确密码后，在有效期内可自由访问所有受保护内容；点击导航栏「退出验证」可手动清除状态。

3. 观看记录管理

观看记录自动存储于本地，在「观看记录」页面可查看所有历史，支持「继续观看」「删除单条记录」「清空全部记录」操作，记录仅保存在本地，隐私更安全。

4. 个性化定制

点击右上角主题图标可切换明暗主题，偏好会自动保存；修改 config.php 可自定义站点信息、主题颜色、片源数量等，支持更换 API 源扩展资源渠道。

⚠️ 重要声明与安全提示

安全最佳实践

- 请设置高强度访问密码（数字+字母+符号），避免使用默认密码，降低被破解风险。

- 建议在服务器端限制 config/ 目录的外部访问，避免配置文件泄露（Nginx 可添加 deny all 规则）。

- 对 API 请求添加频率限制，避免因请求过于频繁导致源站封禁，影响使用。

- 定期更新 API 源与项目代码，修复潜在安全漏洞，保障平台稳定运行。
