# MVideo v2 - 轻量影视搜索播放平台

基于 PHP 开发的轻量化影视搜索与播放系统，主打多源聚合、安全可控、跨端适配，部署简单且支持个性化配置。

## ✨ 核心功能

- 多源聚合搜索：整合多影视源站，覆盖全品类影视资源

- 高清在线播放：支持 m3u8/mp4 格式，搭配专业播放器，播放流畅

- 断点续看：自动记录观看历史与进度，支持续播

- 密码保护：全局/关键词分层保护，可配置验证超时

- 跨端适配：响应式布局，适配桌面/移动设备，支持明暗主题

- 灵活扩展：支持更换 API 源，无数据库依赖，易部署

## 📋 环境需求

- PHP 7.4+（推荐 8.0+），需开启 cURL 扩展

- 支持 Nginx/Apache/IIS 等主流 Web 服务器

- 浏览器：Chrome 60+/Firefox 55+/Safari 12+/Edge 79+

- 项目目录需具备读写权限（用于缓存与会话存储）
